Process — 03

A studio is only as interesting as the questions it asks before it makes anything. So we ask a lot of them.

  1. 01

    Interrogate

    We start with the business, the audience and the competitors — not with moodboards.

  2. 02

    Argue

    Two or three directions, each with a case for why it earns the brand's next five years.

  3. 03

    Build

    A system, a type scale and a front-end, delivered with the rules written down so it survives without us.
